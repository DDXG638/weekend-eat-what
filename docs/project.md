# 周末吃什么 微信小程序 项目方案

## 背景

我想开发设计一款生活类的微信小程序，名字叫 “周末吃什么”，主要为用户提供菜品推荐服务。
目标人群是有生活情调的上班族，在忙碌了五个工作日后，周末自己动手做顿好吃的犒劳自己。
我发现我自己总是想周末做顿美味，但是又不知道要吃什么，于是就在各大短视频平台(B站、小红书、抖音等)搜索灵感，好不容易找到自己想吃的菜品后，又会发现有各种阻力：

1. 担心自己厨艺不好，做得不好吃
2. 食材不好买，去线下超市或者市场买食材费时费力，去线上买菜App买食材不好把握量，特别是单身人士，买多了一顿吃不完
3. 购买食材成本高，特别是对于单身人士，做一顿像样的饭的花费可以点一顿很好的外卖了

各种阻力之后，发现还是点外卖更有性价比。

## 解决的问题

“周末吃什么”主要为用户提供如下帮助：

1. 灵感，通过用户所处地区、菜系和口味的喜好，给用户推荐合适的菜品
2. 制作方法，给用户提供对应菜品的制作方法，内容主要来源于 小红书、B站和抖音 中的视频或帖子
3. 食材选购方式，给用户提供菜品所需食材的购买方式，内容主要来源于 线上买菜App的商品
4. 弃疗方案(外卖)，如果用户觉得整套流程太麻烦了，可以提供兜底方案(外卖)，内容主要来源于 各大外卖App

## 功能

### 主要流程如下

1. 用户提供地区(目前生活的城市/祖籍地)、偏好菜系、偏好口味 和 想吃的食物类型 等信息，系统根据 用户提供的信息、时令季节 和 短视频平台热度 综合推荐出用户可能喜欢的菜品列表供用户选择。
2. 每个菜品信息包含菜品图片、文案描述、涉及食材
3. 用户选择某个推荐的菜品后，界面会展示菜品制作方法 和 食材选购方式，
4. 制作方法：列出 小红书、B站和抖音 视频教程 入口
5. 食材选购方式：列出各大 线上买菜App的商品 购买入口
6. 用户点击某个 制作方法 入口，将会跳转至对应平台的微信小程序，用户去对应平台观看视频
7. 用户点击某个 食材选购方式，将会跳转至对应 线上买菜App的微信小程序
8. 如果用户选择弃疗方案，可以展示 美团/淘宝-闪购/京东 等外卖平台的入口，用户可以点击跳转

### 差异化功能

针对单身人士，可能做完一顿饭后会有很多食材，系统需要根据剩下的食材，匹配一个最满足的菜品，推荐用户再买哪些食材就可以凑成另一道菜品，达到买一次食材可以做多道菜品多顿饭的目的。

## 前期问题调研

### 有哪些可变现方式？

1. 微信小程序广告变现
    1. [banner广告](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/ad/banner-ad.html)
    2. [原生模版广告](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/ad/custom-ad.html)
2. 买菜 App 广告合作，可与美团买菜 / 叮咚 / 朴朴等达成小程序跳转合作，用户点击广告直接进入对应买菜小程序下单
3. 与买菜 App 达成CPS 合作
    1. 美团联盟 CPS 合作，<https://union.meituan.com/>
    2. 叮咚买菜 CPS 合作，<https://www.100.me/home/businessCooperate>
    3. 朴朴超市 CPS 合作
    4. 小象超市等

### 菜品推荐数据从哪里来？

#### 获取数据

1. 定时脚本 + 官方开放接口(抖音、小红书、B站) 拉取相关视频信息
    1. B 站开放平台、抖音开放平台、小红书开放平台，申请「内容搜索 / 热点榜单」接口权限
2. openClaw等AI工具定时获取

#### 分析数据

抖音、小红书、B站 的视频详情页面都不一样，如何从这些 页面或开放接口 中提取出需要的 菜品图片、菜品名、食材 等信息呢？

### 如何更新热点菜品数据？

1. 根据每日获取的菜品数据，分析出热点菜品

### 如何从各大买菜App获取食材信息？

根据 菜品数据 中的食材信息，如何关联到 各大买菜App对应的商品呢？如何获取对应商品的小程序跳转链接呢？
