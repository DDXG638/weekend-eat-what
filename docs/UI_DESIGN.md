# UI设计稿说明

## 设计风格

**温暖治愈的田园风** - 配色选用暖黄、焦糖、米白等色调，给人温馨、放松的感觉。

## 配色方案

| 颜色 | 色值 | 用途 |
|------|------|------|
| 背景色 | #FAF6F1 | 页面主背景 |
| 卡片白 | #FFFFFF | 卡片、浮层背景 |
| 焦糖橙 | #E07A3E | 主色，按钮、高亮 |
| 奶茶棕 | #D4A373 | 辅助色 |
| 暖黄 | #F5B041 | 强调色 |
| 深棕文字 | #3D3129 | 主要文字 |
| 浅棕文字 | #7A6B5E | 次要文字 |
| 边框色 | #E8E0D8 | 分隔线、边框 |
| 标签背景 | #FEF3E2 | 标签、徽章背景 |

## 页面设计

### 1. 首页

**结构**：
- 顶部：搜索栏 + 偏好设置按钮
- 标题区：今日推荐 + 副标题
- 内容区：双列瀑布流菜品卡片

**卡片设计**：
- 圆角卡片，带轻微阴影
- 封面图 + 菜品名 + 菜系/时间 + 标签
- 点击时有缩放反馈

**偏好设置浮层**：
- 从底部滑出
- 卡片式表单设计
- 标签可多选，点击切换状态

### 2. 菜品详情页

**结构**：
- 大封面图（带渐变遮罩和菜品名）
- 信息卡片（烹饪时间、难度）
- 菜品描述
- 食材标签（横向滚动）
- 食材购买入口（多平台一行布局/单平台卡片布局）
- 懒人方案（外卖入口，三平台独立卡片设计）
- 教程卡片列表

**教程卡片**：
- 左侧封面图
- 中间：平台徽章 + 标题 + 来源
- 右侧：跳转提示

**食材购买入口**：
- 多平台时：一行布局，均分宽度，只显示图标+名称
- 单平台时：卡片布局，显示图标+名称+去购买按钮
- 平台：叮咚买菜、朴朴超市、小象超市、多多买菜

**懒人方案（外卖入口）**：
- 三个独立卡片设计
- 渐变背景色区分平台
- 卡片包含：图标、平台名称、描述、按钮
- 平台：美团（黄色渐变）、饿了么（蓝色渐变）、京东（红色渐变）
